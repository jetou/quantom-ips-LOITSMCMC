## Installation

### Standard Install

```console
pip install git+<repo>@<version>
```

`<repo>` can be either
- `https://github.com/quantom-collab/quantom-ips.git`
- `ssh://git@github.com/quantom-collab/quantom-ips.git`

depending on how you normally clone from GitHub.

`<version>` should generally be the most up-to-date release (i.e. `v0.0.4`)

### Optional Dependencies

```console
pip install "quantom-ips[<options>] git+<repo>@<version>"
```
